Firox Linux

A desktop Linux with a familiar classic layout: a taskbar, a two-column Start menu and an XP-style Control Panel. Image-based and self-updating, built on Universal Blue (Fedora Atomic).

What you get

🪟

A classic desktop, rebuilt for Wayland

A taskbar with a firox button, a two-column Start menu, Quick Launch, a notification area, desktop icons and Settings laid out like the XP Control Panel.

It comes in three looks: Modern, Classic and Glass.

🌐

Web apps as real apps

Install any website as a desktop app with its own window, taskbar button and Start menu entry. It uses Firefox and PWAsForFirefox.

🤖

Android apps

Waydroid is built in and has its own folder in the Start menu. The first time you open it, it downloads Android for you. A version with the Play Store is available too.

Safe, automatic updates

Updates that can't break your computer

Firox is image-based: each update is a complete new version of the system, downloaded in the background and switched to at the next restart.

If an update misbehaves, System Restore takes you back to the previous version. Your files, settings and apps aren't touched.

Your files, kept safe

Backup and Restore copies your home folder every hour to a USB drive or a network folder. Backups are plain folders you can open on any computer.

Sync keeps chosen folders the same on all your Firox computers at home. Computers pair with a PIN.

Everything in its familiar place

Click firox for the Start menu.

  • Left column: your pinned and most-used programs, plus All Programs with search.
  • Right column: Documents, Pictures, Computer, Settings, Help and Run.
  • Bottom: Log Off and Turn Off Computer open the dialogs you'd expect.

Formerly FirefoxOS. This distribution was briefly called FirefoxOS, until it was determined that the name was already used, and was quickly renamed Firox Linux. If you installed one of those early versions, switch it to Firox once and it updates normally from then on.

Try it

Already on Fedora Atomic or Universal Blue? Switch to Firox with one command, then restart:

sudo bootc switch ghcr.io/kurodenkou/firox:latest

For a new computer, a computer with an NVIDIA card, or a virtual machine, see Install.
