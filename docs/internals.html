Under the hood

What each part of the desktop is, how it works, and where it keeps its settings. For people who want to change or fix Firox.

Firox is a Fedora Atomic image (Universal Blue's base-main) with its own desktop on top of the labwc Wayland compositor. Most of the desktop is Python and GTK3 programs in /usr/bin/firox-* and /usr/libexec/firox/, with shared code in /usr/lib/firox/python/. See the repository layout for where things are in the source.

The pieces

PieceWhat it is
Window managerlabwc (wlroots, Openbox-style) with the Firox-Luna theme: blue gradient titlebars, rounded minimise/maximise/close buttons
Taskbarfirox-panel (GTK, layer-shell; window list over wlr-foreign-toplevel-management with pywayland): start button, Quick Launch, window buttons, notification area (app tray icons, keep the screen on, volume, battery, update, notifications), clock, on every monitor with that monitor's windows. Windows of the same app share one button ("3 Foot ▴"): click it to pick a window. Click a window button to show or minimise it; right-click for Restore / Minimize / Maximize / Close (or Minimize/Close group); middle-click closes. Quick Launch holds the programs you pin (right-click a program in the Start menu or a window button → Pin to Quick Launch; firox-quicklaunch from a terminal). Drag window buttons and Quick Launch icons to rearrange them. Settings → Taskbar: auto-hide, group similar windows, show Quick Launch, seconds on the clock (or right-click an empty part of the taskbar). Click the speaker for a volume slider with Mute and a choice of speakers/headphones (firox-volume). Click the battery (firox-battery) for charge and time left, battery health, a screen brightness slider and the power mode (Power saver / Balanced / Performance, via tuned-ppd); right-click it for Power Options. Styled by the theme's panel.css; your own rules go in ~/.config/firox/panel.css. waybar is kept as a fallback (and runs instead if you set up ~/.config/waybar). The taskbar and the desktop (pcmanfm-qt) run under /usr/libexec/firox/keep-running, which starts them again if they crash (pcmanfm-qt can when a monitor sleeps or wakes); restarts are logged in ~/.local/state/firox/session.log
Start menufirox-startmenu: Python + GTK3 + gtk-layer-shell. A firox button, user picture header, pinned Internet / Web Apps / Android Apps, most-used programs, All Programs (grouped, with Web Apps and Android Apps folders, type to search), Documents / Pictures / Music / Computer / Network Places, Settings, Bazaar (app store), Help, Search, Run, Log Off and Turn Off Computer dialogs
Desktopfirox-desktop (GTK, layer-shell background on every monitor): the wallpaper on each monitor, the icons (Computer, home folder, Network, Recycle Bin and the files in ~/Desktop) on the main display. Double-click opens; programs (AppImages, binaries) run, asking once before marking a download executable, and scripts ask Run or Open (if one quits at once with an error, its output is shown; logs in ~/.local/state/firox/programs/); drag icons to move them (remembered in ~/.config/firox/desktop-icons.json), onto a folder or the Recycle Bin, or out to other programs; drop files on it to copy them (Shift moves). Right-click: Open, Open With, Cut, Copy, Rename, Move to Recycle Bin, Properties; on the desktop Arrange Icons By, Refresh, Paste, New Folder / Text Document. Keys: Delete, Shift+Delete, F2, F5, Enter, Ctrl+A/C/X/V. Settings → Desktop Background: wallpaper, position (Fill, Fit, Stretch, Center, Tile), colour and which icons show. Settings are in ~/.config/pcmanfm-qt/firox/settings.conf (shared with firox-theme and the Glass taskbar; firox_wallpaper.py). (the folder name is from before Firox had its own desktop)
File manager: Firox ExplorerOpens every folder (/etc/xdg/mimeapps.list; it replaced pcmanfm-qt). GTK, /usr/libexec/firox/firox-explorer (also /usr/bin/firox-explorer; --find DIR searches subfolders, used by Start > Search; --connect opens Connect to Server): Places / Computer (drives, mount and eject) / Network sidebar, Icons or Details view, Back/Forward/Up, address bar, tabs (Ctrl+T/Ctrl+W/Ctrl+Tab, middle-click to open in a tab, drop files on a tab), filter-as-you-type (Subfolders searches every folder inside, in the background, with a Location column), Cut/Copy/Paste (shared with the desktop), Rename, New Folder, Recycle Bin (Restore, Empty), Delete, Properties, Open With, drag and drop, Open Terminal Here. Menu bar: File, Edit, View (sort by name/size/type/date, toolbar/sidebar/status bar), Go, Bookmarks (shared with GTK file dialogs and shown in the sidebar), Tools (Connect to Server, Disconnect All, Options), Help (keyboard shortcuts); view settings in ~/.config/firox/explorer.conf. Connect to Server: Windows shares (SMB/CIFS), SFTP, FTP/FTPS and WebDAV through gvfs, Amazon S3 or compatible (Wasabi, R2, MinIO…) and Backblaze B2 through rclone, mounted for your session only (S3/B2 in a systemd user unit that stops at log off, under /run/user/UID/firox-mounts; the rest under /run/user/UID/gvfs, also as folders for other programs via gvfs-fuse). Connections are saved without secrets in ~/.config/firox/connections.json (0600); passwords and keys go in your login keyring if you tick Remember, and are passed to rclone only in its environment, never on a command line. "Connect when I log in" adds an autostart entry (firox-explorer --connect-saved). Servers and shares in Network open like folders (mounted on double-click). Troubleshooting: S3/B2 log to ~/.local/state/firox/mounts/ID.log; right-click a connection > Test Connection (firox-explorer --test NAME) writes a step-by-step report with secrets blanked. The firewall lets WS-Discovery and NetBIOS replies in so Network can find Windows PCs and NAS boxes. Code: firox_mounts.py
Lock screenfirox-lock (Super+L, Start menu, the idle timer and before sleep): looks like the login screen (the theme's welcome.css) with your account picture, the time and date and your wallpaper, a password box on every monitor, a Caps Lock warning and Turn off computer (Sleep, Turn Off, Restart). Uses the Wayland session-lock protocol through gtk-session-lock, so the screen stays locked even if the lock screen crashes; passwords are checked with PAM (/etc/pam.d/firox-lock). firox-lock -f returns once the screen is locked. swaylock is the fallback where session-lock isn't available
Settingsfirox-control-panel (the Control Panel): Display, Sound, Network, Bluetooth, Printers, Disks, Web Apps, Android, Bazaar, Date and Time, Taskbar, Default Programs (web browser, email, files, music, videos, pictures, text and PDF), User Accounts (change your account picture from a built-in set or any image, or your password; also opened by clicking the picture in the Start menu), System...
Web Appsfirox-webapps: list, open and remove installed PWAs
Loginfirox-welcome, a greetd greeter in cage (firox-greeter): "To begin, click your user name" with everyone's account picture, Other user… for accounts not listed, and Turn off computer (sleep, turn off, restart). Styled to match the default look in /etc/firox/theme. Pictures come from AccountsService (/var/lib/AccountsService/icons), which Settings → User Accounts updates. Uses the keyboard layout chosen when installing. Falls back to gtkgreet if it can't start
DisplaysSettings → Display shows the monitors as numbered screens: pick the main display (full taskbar with tray and clock, the Sidebar and notifications; the others extend the desktop with a taskbar of their own windows, the start button and the clock), Identify shows the numbers on the monitors. The choice is kept per set of monitors in ~/.config/firox/main-display (firox-displays main [NAME|NUMBER]; firox_monitors.py). Settings → Taskbar → Show the taskbar on all displays off: one taskbar, on the main display. Resolution and arrangement… (firox-display) opens wdisplays and saves the layout when you close it (firox-displays save: a kanshi profile per set of connected monitors; resolutions the screen doesn't advertise are saved as custom modes). At login kanshi applies it and firox-displays restore double-checks and re-applies anything that didn't take. Log: ~/.local/state/firox/displays.log
Mouse and keyboardSettings → Mouse: pointer speed and acceleration, left-handed buttons, double-click speed, pointer size, scroll speed, natural scrolling, and a Touchpad tab (tap to click, two-finger or edge scrolling, right-click method, ignore while typing, off when a mouse is plugged in). Settings → Keyboard: repeat delay and rate, Num Lock at login, keyboard layouts with variants and a switching shortcut. Stored by firox-input in ~/.config/firox/input.conf; it writes complete labwc config files to ~/.local/share/firox/xdg/labwc, which labwc reads after ~/.config/labwc (so a personal rc.xml still wins). The layout chosen when installing is the default
Notificationsmako pop-ups, plus a bell in the notification area (firox-notifications) that opens a panel with the last 100 notifications (click one to open its app). Do Not Disturb (in the panel, or right-click the bell) holds pop-ups except urgent ones. Pop-ups are also held while a screen saver runs
Volume and brightness keysfirox-osd: the volume, mute, microphone-mute and brightness keys show a small level popup at the bottom of the screen (also with Do Not Disturb on, and on the lock screen). Volume up unmutes; brightness never goes fully black
UpdatesUpdates download in the background and apply at the next restart. When one is waiting, an icon appears in the notification area (firox-updates): click it to restart, right-click to see which packages change. You also get a notification once per update, and "Firox Linux was updated" after restarting
Snipping Toolfirox-snip (Start → All Programs, or Super+Shift+S to go straight to selecting): snip a rectangle, the whole screen or one monitor, with an optional 3/5/10 second delay. Each snip is copied to the clipboard; mark it up with a pen or highlighter, then Copy, Save (to Pictures/Screenshots) or Save As (PNG or JPEG). Print Screen still saves the whole screen straight to Pictures, and Shift+Print Screen saves an area there
CalendarClick the clock for the time, date and a month calendar (firox-calendar), with a link to Date and Time settings; right-click the clock to open those settings directly
Clipboardfirox-clipboard (cliphist): what you copy stays available after the app you copied it from closes (normally it's lost on Wayland), Super+V clipboard history with search and images, never stores items password managers mark as sensitive, cleared at logout by default. Settings → Clipboard sets the history size or turns it off. The Command Prompt also takes Ctrl+Insert / Shift+Insert, and Waydroid shares the clipboard with Android (python3-pyclip)
Power savingSettings → Power Options (firox-power): on laptops, low-battery warnings (10%, then urgently at 5%) and at 3% the computer goes to sleep (or hibernates or shuts down, as you choose) after a 15-second warning. Also: turn off the monitor, lock the screen and put the computer to sleep after a set idle time, with separate Plugged in and On battery times on laptops. Defaults: lock after 10 min; monitor off after 15 min (5 on battery); sleep never (30 min on battery). Videos and full-screen apps keep the screen on. System defaults: /etc/firox/power.conf
Screen saversSettings → Screen Saver (firox-screensaver): Aquarium (asciiquarium), Matrix (cmatrix), Bonsai (cbonsai), Bouncing firox, Starfield or Blank, full screen on every monitor after a set idle time (off by default), with Preview. Add your own
Desktop Gadgetsfirox-gadgets: a Vista-style Sidebar on the right of the desktop (layer-shell, behind windows) with Clock, Calendar, CPU Meter, Weather (Open-Meteo, no account; set your city in its options), Slide Show (your Pictures folder), Notes, Now Playing (MPRIS: title, artist, cover art, ⏮ ⏯ ⏭; click elsewhere to raise the player), Network Meter (speeds and a graph from /proc/net/dev), Feed Headlines (any RSS/Atom feed, 4 per page, click to open; BBC World News by default), Timer (notification and sound when it's done), Picture Puzzle (4×4 sliding tiles from your Pictures or a Firox wallpaper), Currency (ECB rates via frankfurter.app, no account) and Disk Space (home and plugged-in drives). + Gadgets opens the gallery; hover a gadget for ×, right-click for Options, Move up/down, Close, Hide. On at login; turn it off in Settings → Taskbar. Settings: ~/.config/firox/gadgets.conf
Task Managerfirox-taskmgr (Ctrl+Alt+Del, Ctrl+Shift+Esc): Applications (open windows: Switch To, End Task), Processes (CPU and memory per process, sortable, all users optional, End Process) and Performance (green-on-black CPU and memory history graphs, totals, physical memory, swap). btop is in the Start menu as Resource Monitor
System Restorefirox-restore (Settings → System Restore): lists the installed versions of Firox Linux (rpm-ostree status) and restores the previous one (rpm-ostree rollback, with Undo), keeps a version past later updates (ostree admin pin), shows what changed between versions, cancels a waiting update, and pauses automatic updates so a restored version stays. Files, settings and Flatpaks aren't affected
Backup and Restorefirox-backup (Settings → Backup and Restore): backs up your home folder every hour to a USB drive or a network folder (smb://…), and as soon as the backup drive is plugged in. Each backup is a dated folder with a complete copy, unchanged files hard-linked to the previous one (rsync --link-dest, like the original Time Machine); hourly kept for a day, daily for a month, then weekly, oldest removed when the drive is full. Drives without hard links (FAT/exFAT, most shares) get a Latest copy plus Older versions. Restore window: pick a backup by date, pick files, Restore (or Restore everything). Backups are plain folders you can open anywhere
Syncfirox-sync (Settings → Sync): Firox computers on the same network find each other with Avahi (Bonjour, _firox-sync._tcp), pair with a 6-digit PIN shown on the other computer (HMAC proof over both IDs; the PIN never crosses the network), and keep the folders you tick (Documents, Pictures, Music, Videos, Desktop) the same on all of them. The engine is a private Syncthing instance, local network only (no global discovery or relays); replaced or deleted files are kept 30 days in .stversions
Runfirox-run (Start → Run…, Super+R): an XP-style Run box. Type a program (command or Start menu name), a folder, a file, a web address or any shell command; the rest of a matching command, program or path fills in as you type. Remembers the last 26 (the arrow lists them, the last one is filled in), Browse… picks a file, "Run in a terminal window" shows a command's output, and terminal programs (btop, nano, ssh…) open in one automatically. Old Windows names work: cmd, notepad, calc, control, taskmgr, explorer, msconfig, iexplore, winver, ncpa.cpl…
Wi-Fi and networkfirox-network: click the network icon on the taskbar (signal bars, wired, connecting, off). Wi-Fi on/off switch; networks in range, strongest first with the current one at the top; click one to connect (password box inline, wrong passwords aren't kept), disconnect or forget it. Also your wired connection, VPNs (on/off), Airplane mode (rfkill), Hidden network… and Network Connections… (nm-connection-editor) for networks that need a username or certificate. Uses NetworkManager's libnm; right-click the icon for Network Connections
Bluetoothfirox-bluetooth: click the Bluetooth icon (shown when the computer has Bluetooth). On/off switch; your devices, connected first, with battery level when they report it; click one to connect, disconnect or remove it. Add a device… looks for devices nearby; click one and Pair (it's trusted and connected straight away). Its pairing helper (a BlueZ agent started at login) asks you to compare a code, type a PIN or allow a new device, in a small window. Bluetooth settings… opens Blueman for file sending and audio profiles
Startup Programsfirox-startup (Settings → Startup Programs, or msconfig in Run): tick what starts at login. Add any Start menu program or your own command; untick to pause one without removing it. Entries are standard ~/.config/autostart/*.desktop files, so apps' own "start at login" options appear here too, and they start a few seconds after login once the notification area is up (~/.local/state/firox/startup.log says what started). Desktop Gadgets can be turned off here, and the classic nm-applet and Blueman tray icons turned on (off by default)
Extraszenity for dialogs from shell scripts (zenity --question, --info, --file-selection, --progress…), mako "balloon" notifications, xfce4-terminal "Command Prompt" (tabs, Edit > Preferences; Super+Enter), btop "Task Manager", VLC "Media Player" (music, videos, DVDs; full codecs from the base image)

Building the installer ISO

just build-iso uses bootc-image-builder, which takes the installer's own packages from the repositories configured in the image's /etc/yum.repos.d. Fedora 45 moved its repository files to /usr/share/dnf5/repos.d, so the image links them back into /etc/yum.repos.d (dnf treats same-named files there as overrides, so nothing is listed twice). Without that, every package is "No match for argument". Rebuild the image (just build) before building an ISO from it.
