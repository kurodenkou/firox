Install Firox

Switch an existing image-based Fedora with one command, or build an installer ISO for a new computer.

  • From Fedora Atomic or Universal Blue
  • Fresh install from an ISO
  • NVIDIA graphics
  • Try it in a VM
  • Upgrading from FirefoxOS
  • After your first login

From Fedora Atomic or Universal Blue

Already running an image-based Fedora (Silverblue, Kinoite, Bazzite, Bluefin, Aurora…)? Switch to Firox, then restart:

sudo bootc switch ghcr.io/kurodenkou/firox:latest
systemctl reboot

Your files are kept. Have an NVIDIA card? Use the NVIDIA image instead.

Fresh install from an ISO

Build an installer ISO yourself, which is the usual way. You need the Firox source and just:

just build-iso ghcr.io/kurodenkou/firox latest

Or, in GitHub, run Actions → Build disk images (manual only) and download the anaconda-iso artifact.

The installer creates your user account; there's no separate setup wizard afterwards.

NVIDIA graphics

There's a second image, ghcr.io/kurodenkou/firox-nvidia-open, with NVIDIA's driver built in. It supports GTX 16-series / RTX 20-series and newer cards. It uses Universal Blue's prebuilt, signed open kernel modules, matched to the image's kernel.

On an installed system

ujust install-nvidia

It checks your card, switches to the NVIDIA image and keeps your files and settings. ujust remove-nvidia switches back.

Secure Boot: before restarting, run ujust enroll-secure-boot-key, then choose Enroll MOK on the blue screen at the next boot (password universalblue).

Fresh install

Build the ISO from the NVIDIA image:

just build-nvidia
just build-iso localhost/firox-nvidia-open

The installed system keeps updating from the NVIDIA image: each image records its own update address, and the installer points updates there.

  • Safety net: if a computer with a supported NVIDIA card runs the standard image, a notification at login (shown once) offers to switch.
  • Android apps use software rendering on NVIDIA; ujust setup-waydroid sets that up for you.

Try it in a VM

With the source checked out:

just build
just build-qcow2
just run-vm-qcow2

The VM image has a test user xp with password firox (set in disk_config/disk.toml).

Upgrading from FirefoxOS

This distribution was briefly called FirefoxOS, until it was determined that the name was already used, and was quickly renamed Firox Linux. FirefoxOS machines track the old image, which no longer gets updates. Switch each one once, then restart:

sudo bootc switch ghcr.io/kurodenkou/firox:latest
  • Updates: from then on it updates normally (ujust update).
  • Your settings: on your first login afterwards, your look, Start menu history and desktop settings move to their new places automatically.
  • Old commands: firefoxos-* still work as aliases for firox-*.

After your first login

Web apps

The Firefox runtime for web apps downloads in the background on first login.

To install one, open a site in Firefox, click the PWAsForFirefox toolbar button and choose Install.

Android

Open Start → Android Apps. The first time, it downloads Android for you.

For the Play Store, run ujust setup-waydroid gapps.

More apps

Start → Bazaar opens the Bazaar app store for Flatpak apps. The first time, it offers to install itself.
